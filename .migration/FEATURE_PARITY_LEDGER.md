## 一、四大底层第一性原理不变量（绝对不可倒退）

- [x] **U1｜MFA 提权与取消信号正交公理**：
  - 全站受 MFA 保护端点通过统一拦截器触发 `MfaStepUpModal`，支持按类别（`Platform` / `Mfa` / `Billing` 等）在提权窗口期内免重复验证；
  - `MfaStepUpCancelledError` 必须与 `AbortSignal` / 网络取消严格区分，操作人取消 MFA 后严禁弹出或滞留可保存的空白编辑框；
  - 8 位备用码输入支持自动转大写并正确校验（不含 `0/1/I/O`）。
- [x] **U2｜金额强量纲与东八区时钟同构公理**：
  - 账户充值/退款输入框按「元」录入，向后端整数「分」接口精确换算（严禁 100 倍错账），单价保持高精度小数/微元无浮点误差；
  - 全站列表时间戳、ECharts X 轴、账单对账日历、告警静默时间窗严格绑定东八区（`UTC+8`），严禁读宿主本地时区或错误拼接字面量 `Z`。
- [x] **U3｜真服务端分页与单源状态契约公理**：
  - 全部大数据量列表走真服务端分页并正确透传服务端 `total`，禁止内存假分页或伪造总数；
  - 编码/指纹/流水号列不被硬钳截断；高饱和红色告警仅分配给真实故障/危险操作。
- [x] **U4｜安全域边界不降级 + 无刷新双语热切公理**：
  - 密码策略与 MFA 全局配置保持各自独立提权边界；
  - 中/英文切换必须响应式无刷新热切（严禁 `window.location.reload` 销毁当前页未保存表单状态）；
  - 全仓 `t("...")` 词条 100% 存在于 `zh.json` 与 `en.json`。
