# Mazbri WebUI 视觉与组件设计契约（参照 xBlueNode 架构重构版）

> 本契约用于约束迁移期 `SA-02`（设计系统与原语层）及所有业务泳道开发。**核心理念：保留 Mazbri 品牌基因，全面采用 xBlueNode 的语义 Token、高对比 Hover、整数圆角、薄原语层与紧凑布局纪律。**

## 2. 几何、尺寸与交互硬约束（纳入 `gate-1` 与 `gate-3` 强制断言）

1. **圆角白名单（3 档封死）**：
   - `6px` (`rounded-md`)：所有按钮、输入框、下拉框、日期选择器、分页按钮、SegmentedControl、ActionChip；
   - `10px` (`rounded-lg`)：所有卡片、表格外框、Dialog、Popover；
   - `9999px` (`rounded-full`)：状态胶囊（Badge / StatusBadge）、头像、用户胶囊；
   - **禁止**：`3.333px` / `5.333px` 等任何小数圆角，禁止在按钮/输入框上使用 `rounded-full` 或 `rounded-2xl`。
2. **高度白名单（3 档封死）**：
   - `32px` (`h-8`)：工具栏主/次按钮、搜索框、下拉框、日期控件、分页控件、弹窗底栏按钮；
   - `28px` (`h-7`)：紧凑时间窗开关、图标工具按钮、工作台次级工具栏；
   - `24px` (`h-6`)：表格操作列行内 Link/Text 按钮；
   - **禁止**：同一横排工具栏出现高低不齐的混搭控件。
3. **按钮语义约束**：
   - 批量危险按钮（`删除` / `吊销`）：**0 行选中时隐藏或以低饱和禁用灰态展示**，严禁在 0 选中状态下亮红紧贴 `+ 新建` 主按钮；
   - 主确认按钮文案按语义统一：创建用「确定新建」或「创建」、修改用「保存修改」或「保存」、危险确认用具体动词（「确认删除」「确认吊销」），禁止同一类弹窗随机混用「确定/保存/开通」。

## 3. 四大标准页面骨架与浮层纪律

1. **`DataTablePage`（标准列表页）**：
   - **严禁悬空工具栏**：搜索框、快捷筛选芯片、导入/导出/新建/批量操作必须收敛在主白卡顶部的 `Card Header` 内（左筛选、右操作，底部 `1px solid var(--border)` 分割线），彻底消灭左侧 700px 空白灰带；
   - 数值/金额/耗时/次数列统一右对齐且表头与单元格对齐一致，与右侧左对齐文本列保持合理内边距（`pr-6`），杜绝「运行指标」表格中段视觉断层。
2. **`EntityDetailLayout`（标准详情页）**：
   - 全站统一为「实体身份页头（名称 + 编码一键复制 + 状态胶囊 + 全局主/次操作）→ Tab 栏 → 带明确标题的内容卡片」，对齐租户详情、产品详情、供应商详情与服务详情；
   - **租户详情破坏性重组**：原 8 个碎片化 Tab 合并为 5 个高内聚分组：① `概览 360`、② `基础与凭据`（基本信息 + API 密钥）、③ `接入与安全策略`（IP 白名单 + 缓存限流 + 传输加密）、④ `已开通产品`、⑤ `账户与流水`。
3. **`SettingsSectionLayout`（标准设置页）**：
   - 双栏卡片强制等高拉伸（`grid items-stretch`），所有卡片标题图标风格统一（全部有图标或全部无图标）；
   - **永久废除底部 1200px 空白保存横条**，改为卡片右上角保存或仅在有未保存改动（dirty）时浮现的紧凑操作条。
4. **`FormModal` & `FormDrawer`（三段式浮层）**：
   - 100% 强制三段式：`Header`（含底边 `1px solid var(--border)`）+ 独立滚动 `Body` + `Footer`（含顶边 `1px solid var(--border)`）；
   - 宽度仅允许 3 档：`480px`（确认/简单表单）、`600px`（中等表单）、`760px`（宽表单/导入/代码与详情抽屉）；
   - **强制重表单进抽屉**：超过 6 个字段、含多行代码编辑器或分步向导的交互（`新建告警规则`、`微服务接入`、`新建/编辑配置`、`用户/证书/审计详情`）一律使用右侧 `Drawer`；
   - **强制表单 `label-top` 排版**（特殊紧凑开关行除外），彻底杜绝「对账策略设置」这类标签折行重叠压盖事故。
5. **图表与空态一致性（`ChartCard`）**：
   - 同排图表空态表现必须一致（无流量时统一绘制轻量空态占位或统一零值基线，严禁同排左侧画 0 轴折线、右侧放巨大灰纸箱）；
   - Y 轴格式化函数全轴统一量纲与精度（杜绝下半 `9,000.00` 上半 `12k` 的跳变）；
   - KPI 卡片图标强制非空校验，杜绝空白浅蓝占位块。
